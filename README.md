# **Project Name**

Welcome to the **Bank Management** repository! This project is a comprehensive **application type**, designed with state-of-the-art technology to deliver a seamless and feature-rich user experience.

---

## **Tech Stack**

This project utilizes a modern and efficient tech stack:

- **Next.js**: For server-side rendering and seamless routing.
- **TypeScript**: Ensures type safety and reduces runtime errors.
- **Appwrite**: Provides backend services such as databases, authentication, and storage.
- **Plaid**: Enables secure bank account linking and financial data retrieval.
- **Dwolla**: Facilitates smooth and secure fund transfers.
- **React Hook Form**: Simplifies form handling with high performance.
- **Zod**: For schema validation and error handling.
- **TailwindCSS**: A utility-first CSS framework for building responsive designs.
- **Chart.js**: For creating dynamic and interactive data visualizations.
- **ShadCN**: For a consistent and accessible design system.

## **🔋 Features**

Here’s an overview of the features included in this project:

### **Authentication**
- Ultra-secure SSR authentication.
- Comprehensive validation and authorization mechanisms.

### **Connect Banks**
- Integrates with **Plaid** for linking multiple bank accounts securely.

### **Home Page**
- A dashboard showcasing:
  - Total balance across all connected banks.
  - Recent transactions.
  - Spending analytics by category.

### **My Banks**
- Displays a detailed list of connected banks with:
  - Balances.
  - Account details.

### **Transaction History**
- Provides:
  - Pagination and filtering options.
  - Historical data for all connected bank accounts.

### **Real-time Updates**
- Reflects changes across the application instantly upon actions like connecting new bank accounts.

### **Funds Transfer**
- Enables secure fund transfers using **Dwolla**.
- Includes:
  - Required fields validation.
  - Recipient bank ID integration.

### **Responsiveness**
- Fully responsive design.
- Ensures seamless user experience across desktop, tablet, and mobile devices.

### **And More**
- **Code Architecture**: Highly modular and reusable components.
- **Performance Optimization**: Efficient state management and rendering.

## **🤸 Quick Start**

Follow these steps to set up the project locally on your machine.

### **Prerequisites**

Ensure the following are installed on your system:

- **Git**: Version control system.
- **Node.js**: JavaScript runtime.
- **npm**: Node package manager (comes with Node.js).

### **Installation**

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shrawaniwagh2003/Bank-Managment.git
   cd project-name
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up environment variables:**
   - Create a `.env.local` file in the root directory.
   - Add necessary API keys and configuration details for **Appwrite**, **Plaid**, and **Dwolla**.

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Access the application:**
   - Open your browser and navigate to `http://localhost:3000`.
